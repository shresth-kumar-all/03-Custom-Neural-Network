02-Training_Data//tts_train_x: "tts" means "train-test-split" model was used, "train" means this is training data, "x" (0<x<1) represents the fraction of the data went into training

03-Testing_Data//tts_test_y: "tts" means "train-test-split" model was used, "test" means this is testting data, "y" (0<y<1) represents the fraction of the data went into testing

processing//Bias_Pools//B_x: its a csv containing bias values of the "x_th" layer (shaped like the layer itself)
processing//Layers//Layer_y: its a csv containg the value of each node after calculation for the next layer to reference
processing//Weight_History//whist_x-to-(x+1): its a csv containing the time sequenced weights of all connections between the "xth" and the "(x+1)th" layer
processing//Weight_Pools//W_x-to-(x+1): its a csv containing the current values of all connections between "xth" to "(x+1)th" layer
processing//coordination_factor.csv: contains the epoch number to sync all systems
processing//rms_errors: has "epoch-rms_errors" pairs
